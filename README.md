# Concepts and Code: Decision Trees
This repository contains the files associated with the StatQuest "Concepts and Code" livestream for [Decision Trees](https://youtube.com/live/z6V3keTibCA). BAM!

**NOTE!!!** In the livestream I had trouble getting the classification trees to work well in Python. Ultimately, the reason for
problems was tracked to the code that did the One-Hot Encoding of the categorical variables. The code that was originally generated by the AI omitted a key part to the command, and, by default, all columns that were not One-Hot Encoded were dropped. As a result, _the One-Hot Encoding process removed all of the numeric columns from the dataset_, and thus, removed a lot of useful data.

In the python file here, I have corrected the mistake and now the numeric columns are retained through the process of One-Hot Encoding.
